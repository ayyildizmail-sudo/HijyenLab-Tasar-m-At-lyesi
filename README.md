# HijyenLab Tasarım Atölyesi

Müşterinin logosuyla ıslak havlu, ıslak mendil ve oshibori ambalajını tarayıcıda gösterip ön teklif hazırlayan uygulama.

- Güncel durum, yayın bilgisi, test kapısı ve açık işler: **[DURUM.md](DURUM.md)**
- Testler: `npm install`, sonra `node scripts/run-tests.mjs`
- Ürün kuralları: `frontend/product-catalog.js`. Değiştirdikten sonra `node scripts/sync-commercial-rules.mjs` çalıştırın.
- Eski sürüm notları: `docs/arsiv/`
