# V66 — automatic bounded white-carrier preview

Customer-reported failure: a sideways product photograph opened manual corner selection or left the mockup empty. The existing white-carrier completeness guard compared orange logo colors with brown wood outside the carrier. A second crop-padding audit treated unrelated outside-carrier pixels as claimed artwork.

## Change
- Completeness compares against a separately detected neutral physical-carrier domain.
- Final source-color retention is audited against independently computed un-eroded carrier support, not the final successful ink mask.
- A bounded colored-header / neutral-subtitle layout can establish upright orientation. Existing two-independent-row fine correction levels the complete mark without redrawing glyphs.
- Source-pixel glyph-region refinement removes carrier residue while preserving colored strokes, black outlines, holes and associated detached marks. Retention is checked after refinement.
- Only proposals meeting the independent domain, completeness, row, orientation and retention requirements apply automatically to the mockup. Ordinary visual design approval remains; technical area/corner selection is not a customer step.
- Unsupported proposals remain unsupported. No wrong or incomplete design is made commercially valid by hiding its warning.
- Photographic RGB shades no longer masquerade as confirmed physical inks. Original diagnostics are retained. Native-artwork genuine three/four-color rules and stale-source checks remain intact.

## Evidence
- Original reported image processed through the actual extraction route, in all four orientations; no filename/brand/hash lookup or manually supplied crop coordinates in runtime.
- Targeted source tests cover wood with similar hues, missing on-carrier detail, detached dots/cedilla/trademark, competing row ambiguity, and late browser module loading.
- Direct-apply lifecycle tests exercise decode failure, reset/new upload during decode, source identity and manual ground intent.
- Full automated run: 527 tests, 516 passed, 11 explicitly skipped, zero failures. Actual private-source focused checks were run separately.
