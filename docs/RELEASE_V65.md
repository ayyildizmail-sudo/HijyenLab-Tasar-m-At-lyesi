# V65 integration record

This is an idea-preview and local quotation application, not a print-ready artwork service.

## Integrated changes
- Source-ground scope: colored logo panels remain local; scene/background samples do not automatically become the whole package ground. Explicit customer ground selection takes precedence.
- Original artwork, ink families and white substrate openings remain separate from package material rendering. White OPP is not an extra printing ink.
- BM21 7×12 uses the approved soft-satin, reduced-wrinkle material on both sides. The rear no longer inherits the roll-product CSS silhouette.
- Visible artwork bounds drive proportional placement. New input invalidates older processing results and commercial output.
- Same-step upload completion no longer starts an unnecessary smooth page scroll.
- Product changes retain compatible quantity and towel fragrance choices; incompatible choices are reconciled against existing product rules with an explanation.
- Conservative native-artwork display cleanup does not modify original pixels used for commercial analysis, remove ink families, or recolor the brand. Large/uncertain/photo/gradient inputs can decline this optional cleanup.
- Three-ink and continuous-gradient capability checks remain separate from visual readiness. Four-ink originals are not silently turned into three-ink approved jobs.
- Local content checks and server submission guards exist. The contextual moderation provider and live lead/email activation are not configured by this release.

## Evidence and limits
The full automated test run on final frontend bytes reported 509 tests: 500 passed, 9 explicitly skipped, zero failures. TypeScript and 82 local versioned asset references passed validation. Browser acceptance is recorded separately after the build.

Generated design examples shown in chat are artistic previews, not proof that the application automatically reproduces every input. General photo-to-brand extraction, full gradient-to-flexo adaptation and all-source semantic interpretation remain incomplete. No universal success, legal-content coverage, physical color fidelity or print-readiness guarantee is made. Actual iPhone/Safari device testing has not been performed in this cloud workspace.

No main HijyenLab accounting file, customer record, invoice, list or formula was edited as part of this application work. No new paid service, credentials, email delivery or customer submission service was activated.

## Targeted browser acceptance on this release
Verified desktop managed-browser outcomes: BM21 rectangular rear/material correction in sampled colors, inverse-white artwork retained inside its local dark panel on white packaging, explicit navy selection retaining that panel, one immediate upload/reset returning the explicit blank-start state, and a local BM21 quote (10,000 units, two inks, freight) totaling 18,000 TL excluding VAT with no transmission. Browser infrastructure interrupted a second reset attempt. Full fifty-source replay, complete gradient/native-three matrix, draft-reopen chain and physical iPhone testing were not completed on this build. Historical runs are not substituted for these missing checks.
